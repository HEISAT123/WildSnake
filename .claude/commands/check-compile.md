Проверь компиляцию проекта.
1. Если подключён Unity MCP и редактор открыт - прочитай ошибки из консоли редактора.
2. Иначе запусти `powershell -NoProfile -File tools/check-compile.ps1` (нужна переменная UNITY_EXE, редактор должен быть закрыт).
3. Сгруппируй ошибки `error CS...` по файлам, найди причину каждой, исправь и повтори проверку до чистого результата.
4. В конце коротко перечисли, что исправлено.
